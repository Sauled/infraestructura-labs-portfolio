# Portafolio Técnico de Infraestructura, Redes y Ciberseguridad

Repositorio de laboratorios prácticos, topologías de red y memorias técnicas enfocadas en operación de infraestructura corporativa, conectividad multi-sucursal, seguridad perimetral, administración de sistemas y servicios híbridos.

Cada laboratorio documenta el escenario operativo, diseño de topología, configuración aplicada, pruebas de validación y análisis de resolución de fallas (*troubleshooting*) siguiendo buenas prácticas de gestión de cambios y soporte.
